explicacion:
La clase `SumaDigitos` calcula la suma de los dígitos de un entero positivo mediante recursión. El método público valida el número y luego llama al método recursivo privado; los valores menores o iguales a cero se rechazan porque no pertenecen al dominio definido para este ejercicio.

El caso base se da cuando `n < 10`. Como la validación garantiza que `n` es positivo, en ese punto queda un único dígito y la función lo devuelve directamente. Para los demás valores, `n % 10` obtiene el último dígito y `n / 10` lo elimina usando división entera. Por eso, cada llamada devuelve el dígito aislado más la suma recursiva de los dígitos restantes.

Por ejemplo, para `sumaDigitos(305)`, la fase de ida reduce el número y deja sumas pendientes:

$$sumaDigitos(305) = 5 + sumaDigitos(30)$$
$$sumaDigitos(30) = 0 + sumaDigitos(3)$$
$$sumaDigitos(3) = 3$$

Al regresar del caso base, se resuelven las llamadas: `sumaDigitos(30)` devuelve $0+3=3$ y `sumaDigitos(305)` devuelve $5+3=8$. La pila guarda esos dígitos pendientes hasta que se obtiene el resultado de las llamadas más pequeñas.

El método `parsear` convierte texto a entero y rechaza texto vacío, no numérico o fuera del rango de `int`. La función también rechaza el cero: como `0 / 10` sigue siendo `0`, no alcanzaría el caso base `n < 10` de la manera prevista para números positivos. El programa prueba entradas válidas, entradas inválidas y `Integer.MAX_VALUE`, cuya suma de dígitos es `46`.

Si el número tiene $d$ dígitos, se realizan $O(d)$ llamadas y se usa $O(d)$ espacio en la pila. Para un entero positivo de tipo `int`, la profundidad máxima es de diez llamadas, porque el mayor valor positivo tiene diez dígitos.
