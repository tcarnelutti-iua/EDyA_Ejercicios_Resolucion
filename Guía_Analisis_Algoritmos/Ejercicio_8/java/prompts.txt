explicacion:
La clase `InvertirCadena` invierte una cadena de texto mediante recursión, sin usar ciclos. El método público valida la entrada y luego llama al método recursivo privado; el valor `null` se rechaza porque no se puede separar en primer carácter y resto.

El caso base se da cuando la longitud de la cadena es 0 o 1. Tanto la cadena vacía como la de un único carácter ya están invertidas, por lo que se devuelven tal cual. Para los demás casos, `charAt(0)` aísla el primer carácter y `substring(1)` obtiene el resto. Así, cada llamada devuelve la inversión del resto seguida del primer carácter.

Por ejemplo, para `invertir("casa")`, la fase de ida reduce la cadena y deja concatenaciones pendientes:

$$invertir("casa") = invertir("asa") + 'c'$$
$$invertir("asa") = invertir("sa") + 'a'$$
$$invertir("sa") = invertir("a") + 's'$$
$$invertir("a") = "a"$$

Al regresar del caso base, se resuelven las llamadas: `invertir("sa")` devuelve `"as"`, `invertir("asa")` devuelve `"asa"` y `invertir("casa")` devuelve `"asac"`. La pila guarda esos caracteres pendientes hasta que se obtiene el resultado de las llamadas más pequeñas; por eso el primer carácter del original termina en la última posición.

La función conserva las mayúsculas y minúsculas porque solo reordena caracteres, sin transformarlos. Además, rechaza `null` con un mensaje descriptivo. El programa prueba cadenas vacías, de un carácter, palíndromos como `"reconocer"` y entradas mixtas con mayúsculas y espacios.

Si la cadena tiene $n$ caracteres, se realizan $O(n)$ llamadas y se usa $O(n)$ espacio en la pila. En cada nivel se crea una subcadena y se concatena un carácter, por lo que el costo de tiempo total es $O(n^2)$ con la concatenación directa; una cadena vacía o de un solo carácter detiene la recursión de inmediato.
