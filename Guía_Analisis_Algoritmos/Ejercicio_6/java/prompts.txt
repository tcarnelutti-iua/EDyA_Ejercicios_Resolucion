explicacion: 
La clase `ContarDigitos` calcula cuántos dígitos tiene un entero positivo. Su método público `contarDigitos(n)` valida primero la entrada y luego delega el cálculo a un método recursivo privado. Si `n` es cero o negativo, se lanza una excepción porque el ejercicio solo admite enteros positivos.

El caso base es `n < 10`. Como la validación garantiza que `n` es positivo, esto significa que está entre `1` y `9`; cualquiera de esos valores tiene exactamente un dígito, así que la función devuelve `1`.

Para números mayores, la función devuelve `1 + contarDigitos(n / 10)`. La división entera entre `10` elimina el último dígito. Por ejemplo, con `305`, la fase de ida queda así:

$$contarDigitos(305) = 1 + contarDigitos(30)$$
$$contarDigitos(30) = 1 + contarDigitos(3)$$
$$contarDigitos(3) = 1$$

Al regresar desde el caso base, cada llamada suma uno por el dígito que eliminó: `contarDigitos(30)` devuelve `2` y `contarDigitos(305)` devuelve `3`. Esa es la fase de vuelta o desenrollado de la pila.

El método `parsear` convierte una cadena en entero y rechaza entradas vacías o no enteras. El `main` ejecuta pruebas para números de uno o varios dígitos, entradas inválidas y `Integer.MAX_VALUE`. Este último tiene diez dígitos, así que para cualquier `int` positivo la recursión tiene como máximo diez niveles.

Si el número tiene $d$ dígitos, la función realiza $O(d)$ llamadas y usa $O(d)$ espacio en la pila. Como el número se divide entre diez en cada paso, $d$ es aproximadamente $\log_{10}(n)$.
